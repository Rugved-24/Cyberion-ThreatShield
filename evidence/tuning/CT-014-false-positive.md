## Trade-off accepted

The two filters are narrow and specific to this recording's share layout. An environment where backups run under a named service account, or where a different policy file set is replicated, would need both filters revisited. The rule matches nothing in this telemetry and must not be read as evidence that lateral movement is covered.

## Observations

- Before: all three matches were domain controller SYSVOL replication by a machine account for group policy templates.
- After: the rule is silent on this recording.
- The source dataset directory name refers to a PsExec-style lateral movement scenario, but no record in the capture shows remote service execution, and a directory name is not evidence. This is recorded so that the absence is explicit rather than assumed.
