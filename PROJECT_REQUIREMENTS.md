## Recorded limitations

Requirements this environment cannot legitimately satisfy. These are disclosed
gaps, not incomplete work, and are never counted as failures. Each one states
what was not done and why, so that a reviewer can see the boundary of the work.

### R-4.2-03-LIM

- **Requirement affected:** R-4.3-01 / R-4.6-01 partial scope
- **What was asked:** Close the three evidence gaps T1547.001 Registry Run Keys / Startup Folder, T1110.003 Password Spraying and T1486 Data Encrypted for Impact.
- **Effect on the requirement:** These three techniques stay Not Covered. They cannot be demonstrated with the two selected recordings, which contain no run-key write, no event 4625 authentication failure, and no labelled encryption sequence.
- **Why it cannot be satisfied here:** Closing them would require locally generated telemetry. This host has no hypervisor, no VirtualBox or VMware, no working Docker daemon and no Hyper-V compute service, so no isolated Windows test VM can be created. The PRD and the engagement instruction both forbid running attack simulation on the user's daily-use environment, so the Atomic Red Team route is closed as well.
- **Evidence:** docs/environment-inventory.json records hypervisor_present and platforms_on_path as absent. coverage/matrix-v2.md records the minimum dataset each gap needs.
- **What was deliberately not done:** No rule was written for these techniques. No telemetry was synthesised. They are reported as Not Covered with a stated visibility gap.

### R-2.7-06-LIM

- **Requirement affected:** R-2.7-06 / quality of false-positive review
- **What was asked:** Measure the false-positive rate of every rule against a clean recording of normal business activity.
- **Effect on the requirement:** 12 of 21 techniques are capped at Partially Covered rather than Covered. The coverage matrix is not overstated, and the cap is deliberate.
- **Why it cannot be satisfied here:** Both selected recordings are adversary-emulation captures. They contain no baseline of ordinary activity. Three rules were measured against attributable benign background inside the captures, which is real evidence but not a clean-environment baseline.
- **Evidence:** evidence/tuning/benign-baseline.json states explicitly that it is not a separately collected clean baseline.
- **What was deliberately not done:** No benign baseline was invented. The measured figures come from scripts/tune.py against real records.

### R-9-02-LIM

- **Requirement affected:** R-9-01 distribution
- **What was asked:** Clear redistribution terms for the selected public datasets before external publication.
- **Effect on the requirement:** The repository is not published externally. A redacted copy path exists but publication remains gated on a rights review.
- **Why it cannot be satisfied here:** The pinned upstream files carry conflicting MIT and GPL-3.0 licence labels, which is a genuine unresolved ambiguity, not a formality.
- **Evidence:** references/OTRF-LICENSE, references/OTRF-README.md, docs/datasets.md, SECURITY.md.
- **What was deliberately not done:** No licence claim was invented or assumed.
